# Sound licenses (electric typewriter set)

All sounds in this folder come from one recording on Freesound:

- Title: "COMType_Sears Electric Twelve, Repetitive Patterns_ShaneVincent_MKH416_20250519"
- Author: ShangusBurger (Shane Vincent), uploaded May 20th, 2025
- Source URL: https://freesound.org/people/ShangusBurger/sounds/807926/
- Machine: Sears Electric Twelve (electric typebar office/portable typewriter), as stated on the source page.
  Recorded with a Sennheiser MKH-416 microphone (mono) on a Zoom H8.
- License: Creative Commons 0 (CC0 1.0 Universal, public domain dedication),
  https://creativecommons.org/publicdomain/zero/1.0/ . The source page says: "You can copy, modify,
  distribute and perform the sound, even for commercial purposes, all without the need of asking
  permission to the author." Attribution is not required.

Downloaded file: the public HQ preview of the sound,
https://cdn.freesound.org/previews/807/807926_11744683-hq.ogg (Ogg Vorbis, 96 kHz, both channels
identical, 188.0 s, SHA-256 eed53783860462ea61e8a3167847869acafa6f97e20de170419a7517c2b3aaca).
The original WAV needs a Freesound login, so the preview (lossy, about 166 kbit/s) was used.

Processing (all files): decode to mono, 60 Hz family hum removed from the one-shots (90 Hz high-pass
plus notches at 120/180/240/300 Hz, zero phase), cut so that the strike starts about 1 ms into the file
(the ~30 ms key/cam noise before each strike is left out), 0.5 ms fade-in, cosine fade-out,
level normalization, resampled to 44.1 kHz / 16 bit with triangular dither.
